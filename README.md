# 🪙 ZakatFlow - Dynamic Zakat Tracker

**ZakatFlow** adalah aplikasi web kalkulator dan pelacak zakat mal dinamis yang dirancang sesuai kaidah **Mazhab Syafi'i**. Aplikasi ini secara otomatis memantau fluktuasi saldo tabungan, melacak titik awal haul, melakukan *auto-reset* perhitungan saat terjadi *Inqitha' al-Haul* (saldo terputus di bawah nisab), serta memberikan proyeksi tanggal jatuh tempo zakat secara presisi.

## ✨ Fitur Utama

- 📐 **Kalkulasi Sesuai Mazhab Syafi'i:** Mendukung prinsip *Inqitha' al-Haul* (reset otomatis perhitungan haul jika saldo turun di bawah nisab).
- 🌙 **Konversi Kalender Hijriah Presisi:** Mengonversi tanggal Masehi ke Hijriah (Umm al-Qura) secara akurat tanpa *bug* penanggalan bawaan browser.
- 🥇 **Nisab Dinamis Emas Realtime:** Perhitungan berbasis standar nisab 85 gram emas murni.
- 💵 **Format Input Otomatis:** Pemisah ribuan otomatis (titik) pada nilai nominal saldo untuk kenyamanan input pengguna.
- 📄 **Cetak & Export PDF:** Fitur bawaan untuk mencetak laporan ringkasan status haul dan riwayat transaksi ke format PDF.
- 💾 **Penyimpanan Lokal (LocalStorage):** Data saldo dan riwayat transaksi tersimpan aman di browser pengguna.
- 📱 **Desain Mewah & Responsif:** Menggunakan tema Emerald & Gold dengan antarmuka yang nyaman di HP maupun PC.

## 🚀 Cara Penggunaan

1. Buka aplikasi melalui [ZakatFlow Live App](https://fatur62.github.io/dynamic-zakat-tracker/).
2. Masukkan tanggal pencatatan dan jumlah saldo tabungan Anda saat ini.
3. Klik **Catat Perubahan Saldo**.
4. Sistem akan otomatis menganalisis status haul, tanggal jatuh tempo zakat, serta estimasi zakat (2.5%) yang wajib dikeluarkan.
5. Gunakan tombol **Cetak / Simpan PDF** untuk mengunduh laporan riwayat transaksi.
